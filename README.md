# Retail Transactions ETL & Power BI Dashboard

## Project Overview

This project analyzes retail transaction data using an end-to-end data analytics workflow.

The dataset was cleaned and transformed using Power Query (ETL), analyzed using DAX, and visualized through an interactive Power BI dashboard.

## Tools & Technologies

- Microsoft Excel / CSV
- Power Query
- Power BI
- DAX

## ETL Process

The project follows these steps:

1. Imported raw retail transaction data
2. Cleaned and transformed the data using Power Query
3. Handled missing and inconsistent values
4. Removed duplicate records
5. Corrected data types and standardized fields
6. Created calculated columns
7. Loaded the transformed data into Power BI
8. Created DAX measures for analysis
9. Built an interactive Power BI dashboard

## Key DAX Measures

- Net Sales
- Total Transactions
- Units Sold
- Average Order Value

## Dashboard Analysis

The dashboard provides insights into:

- Monthly Net Sales Trends
- Sales by Product Category
- Sales by Order Status
- Net Sales by City
- Overall Sales Performance
- Transaction Volume
- Units Sold
- Average Order Value
